# Object Oriented Programming in Python

## How I Learned

I learned OOP concepts step by step by understanding the basic idea, writing a small example, running the code, and saving each concept in a separate Python file.

## Concepts Practiced

- Classes and Objects
- Constructor and initialisation
- Class Methods
- Static Methods
- Inheritance
- Getters and Setters
- OOP Principles

## OOP Principles

- Encapsulation - keeps data and methods together inside a class.
- Abstraction - hides unnecessary details and shows only what is needed.
- Inheritance - allows a child class to use features of a parent class.
- Polymorphism - allows the same method name to behave differently.

## Files

## Key Learning

- `self` refers to the current object.
- `cls` refers to the class.
- `__init__()` runs when an object is created.
- Inheritance helps reuse code.
- Getters and setters help control access to data.
- OOP helps organize code into reusable classes and objects.
