# Intermediate Python Learning

## How I Learned

I started by revising the basic Python concepts and then moved into intermediate topics one by one.

For each concept, I followed a simple process:

1. Understand the basic meaning of the concept.
2. Study and research about that on Google or any resources online.
3. Write a small and simple Python example.
4. Run the code and check the output.
5. Modifying values and trying again.
6. Save each concept in a separate `.py` file.
7. Push each file to GitHub with an individual commit.

- Keeping the examples simple for better understanding
- Understanding what each method or function does

I focused more on understanding the logic and syntax instead of memorizing code.
